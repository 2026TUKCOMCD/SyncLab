6. 영상 길이당 예상 소요 시간
━━━━━━━━━━━━━━━━━━━━━━━━
(ai_highlight.py 의 estimate_processing_seconds() 계산 로직 기준,
 YOLOv8n 공개 벤치마크를 참고한 근사치이며 이 환경에서 실측하지 않은
 추정값임 — 실제 서버의 CPU/GPU 사양에 따라 달라질 수 있음)

  5fps 샘플링 기준:
    GPU(CUDA) 사용 시   : 영상 1분당 약 6초 처리 (+ 고정 오버헤드 약 5초)
    CPU 전용 사용 시     : 영상 1분당 약 35초 처리 (+ 고정 오버헤드 약 5초)

  예시:
    5분 영상  → GPU 약 35초 / CPU 약 3분
    10분 영상 → GPU 약 65초 / CPU 약 6분
    30분 영상 → GPU 약 3분  / CPU 약 18분

  → 위 수치는 AIHighlightPanel.jsx에서 "예상 약 X:XX" 형태로
    사용자에게도 진행률 화면에 표시되도록 구현함 (경과 시간과 함께 노출).
  → 실제 배포 서버의 GPU/CPU로 한 번 실행해 본 뒤, 이 파일의
    EST_SEC_PER_MIN_GPU / EST_SEC_PER_MIN_CPU 상수를 실측값으로
    보정하는 것을 권장함.
