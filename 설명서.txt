  [섹션 1] 개발배경
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  스포츠 경기, 공연, 학내 행사 등의 현장을 단일 카메라로 촬영하면
  특정 방향의 장면만 기록되어 결정적인 순간을 놓칠 수 있다. 전문적인
  다각도 촬영은 방송급 장비와 전문 인력이 필요하여 아마추어 팀이나
  소규모 행사에서는 현실적으로 도입하기 어렵다.

  반면 스마트폰 카메라의 성능은 전문 장비에 근접할 수준으로 발전하여,
  여러 대의 스마트폰을 동시에 활용한 다각도 촬영은 기술적으로 충분히
  가능한 환경이 되었다. 그러나 기기마다 내부 클록의 오차가 발생하여
  각 영상의 절대 시작 시간이 일치하지 않고, 이를 동기화하여 함께
  편집할 수 있는 전용 도구가 존재하지 않아 활용에 한계가 있었다.

  본 프로젝트는 NTP(Network Time Protocol) 기반의 절대 시간 동기화
  기술을 적용하여 여러 스마트폰이 촬영한 영상의 시작 시간을 밀리초
  단위로 정밀하게 일치시키고, 웹 브라우저에서 바로 다각도 영상을
  편집할 수 있는 통합 플랫폼 'SyncLab'을 개발하였다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [섹션 2] 개발목표 및 내용
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  촬영부터 편집·내보내기까지 전체 영상 제작 파이프라인을 하나의
  플랫폼으로 통합하는 것을 목표로 다음 기능을 개발하였다.

  ① Android 모바일 앱 — NTP 외부 서버로 절대 시간을 보정한 뒤
     녹화 시작 시각을 메타데이터로 기록하고, 원본 영상을 AWS S3에
     직접 업로드한다.

  ② FastAPI 백엔드 — S3에 저장된 원본 영상을 FFmpeg로 트랜스코딩
     하여 편집용 저화질 프록시 영상을 생성하고, 세션·영상 메타데이터
     를 MySQL DB로 관리한다.

  ③ React 웹 편집기 — NTP 절대 시간 기준으로 다각도 영상을 자동
     동기화하여 멀티뷰로 재생하고, 원하는 각도를 선택·전환하며
     컷 편집 구간을 기록한다.

  ④ 최종 렌더링 — 편집 정보를 서버로 전송하면 FFmpeg가 원본 영상
     으로 고화질 최종 영상을 합성하고 다운로드 링크를 제공한다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [섹션 3] 기대효과 및 시장성  (불릿 형식)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • 아마추어 스포츠 팀·동호회·학교 행사에서 전문가 수준의
    다각도 영상 제작 가능
  • 스마트폰만으로 촬영하므로 전문 장비 대비 비용 대폭 절감,
    영상 제작 진입 장벽 완화
  • 스포츠 전술 분석, 공연·발표 기록, 교육 콘텐츠 등
    다양한 분야로 활용 확장 가능
  • 숏폼·1인 미디어 시장 성장과 함께 다각도 편집 수요 증가


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [섹션 4] 개발결과
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Android 앱에서 외부 NTP 서버의 절대 시각을 기록하여 기기 간
  클록 오차를 제거하고, 대용량 원본 영상을 AWS S3에 안정적으로
  업로드하는 기능을 구현하였다.

  FastAPI 백엔드는 S3 Presigned URL 발급, FFmpeg 기반 비동기
  트랜스코딩, 세션 관리 API를 제공하며, React 웹 편집기는 NTP
  오프셋을 반영한 멀티뷰 동기화 재생과 구간별 컷 편집 기능을
  갖추었다. 전체 시스템은 Docker 컨테이너로 패키징되어 AWS EC2
  (Ubuntu 24.04 LTS) 환경에 배포되었으며, 실제 도메인
  (www.synclab.click)을 통해 서비스를 운용 중이다.
